# Query Engine Overhaul Parity Inventory

## Purpose

This file is the working parity inventory for the query-engine overhaul.

It tracks legacy facet families, result paths, and result shapes against current composed-path support.

It is a migration-tracking artifact, not a durable description of shipped runtime behavior.

## Maintenance Rule

Update this file when support status changes for a legacy capability that matters to the overhaul.

Keep entries explicit about whether support is current, partial, unsupported, ambiguous, deprecated, or deferred.

When support changes because the grouped live matrix, focused live tests, or the composed fallback boundary changes, update the affected rows in the same change.

Move long-lived architectural or requirements truth into `docs/DESIGN.md` or `docs/REQUIREMENTS.md` instead of expanding this file into a durable system document.

## Status Values

Use these values in the `Current Status` column:

- `Supported`
- `Partial`
- `Unsupported`
- `Ambiguous`
- `Deprecated`
- `Deferred`
