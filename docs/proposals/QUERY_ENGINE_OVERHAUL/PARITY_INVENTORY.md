# Query Engine Overhaul Parity Inventory

## Purpose

This file is the working parity inventory for the query-engine overhaul.

It tracks legacy facet families, result paths, and result shapes against current composed-path support.

It is a migration-tracking artifact, not a durable description of shipped runtime behavior.

## Maintenance Rule

Update this file when support status changes for a legacy capability that matters to the overhaul.

Keep entries explicit about whether support is current, partial, unsupported, ambiguous, deprecated, or deferred.

When support changes because the grouped live matrix, focused live tests, or the composed fallback boundary changes, update the affected rows in the same change.

Move long-lived architectural or requirements truth into `docs/DESIGN.md` or `docs/REQUIREMENTS.md` instead of expanding this file into a durable system document.

## Status Values

Use these values in the `Current Status` column:

- `Supported`
- `Partial`
- `Unsupported`
- `Ambiguous`
- `Deprecated`
- `Deferred`

- `ResultService` now compiles supported result requests through an explicit `ResultProjectionHandoff`, and focused unit coverage now proves that `TabularResultSqlCompiler` and `MapResultSqlCompiler` prepend the handoff SQL prologue while `ResultService` uses the handoff builder instead of calling `QuerySetupBuilder.Build(...)` directly for the supported unit slice.
- Focused live result parity now directly compares composed and forced-legacy outputs for the validated range-filtered tabular slice, the validated country-filtered map slice, and the full active prefixed `feature_type:feature_type` tabular family.
- The active prefixed `sample_groups` result family is now promoted through `archaeobotany`, `pollen`, `geoarchaeology`, `dendrochronology`, and `ceramic` for both the validated tabular and routed map slices.
- The full active prefixed `genus:genus` tabular family is now validated on the composed result path through palaeoentomology, archaeobotany, pollen, and dendrochronology, and the full active prefixed `feature_type:feature_type` tabular family is now also validated through palaeoentomology, archaeobotany, pollen, geoarchaeology, dendrochronology, and ceramic.
- The latest broader result regression refreshes are 59 live tests and 253 controller tests passed.
- `docs/DESIGN.md` and `docs/DIAGRAMS.md` now record the active result-projection handoff boundary, the current result-generation flow, and the core composed handoff interactions so the durable architecture docs match the current Phase 4 runtime.
- Phase 4 is now closed on the validated result-projection support surface above, with the remaining routes below treated as explicit follow-up exceptions.
- The active adjacent prefixed `data_types`, `country`, `sample_groups`, `genus`, and `feature_type` families are exhausted apart from commented isotope residue.
- The explicit live result exceptions now include `species:species`, `sample_group_sampling_contexts:sample_group_sampling_contexts`, and `tbl_biblio_modern:tbl_biblio_modern`, plus archaeobotany `modification_types:modification_types` and archaeobotany and pollen `abundance_elements:abundance_elements` until focused result-projection probes confirm their route contracts.
- Commented isotope `sample_groups`, `country`, `data_types`, and `sites` routes remain outside the live result surface because they are currently inactive.
